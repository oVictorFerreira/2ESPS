Documentação • Operadores

Os endpoints de operadores são responsáveis pelo gerenciamento das organizações espaciais vinculadas aos satélites cadastrados no sistema, permitindo consultas, registros e remoções.

GET
/api/operators

Retorna todos os operadores espaciais cadastrados no sistema.

GET
/api/operators/id/{operatorId}

Retorna um operador específico a partir do ID informado.

GET
/api/operators/role/{role}

Retorna operadores filtrados pelo papel operacional exercido.

Exemplos de OperationalRole 

OWNER
OPERATOR
BUILDER
LAUNCHER
GET
/api/operators/name/{opNameFragment}

Retorna operadores contendo determinado fragmento no nome.

Exemplo 

/api/operators/name/NASA
GET
/api/operators/country/{country}

Retorna operadores vinculados a determinado país.

Exemplos de Country 

USA
RUSSIA
CHINA
JAPAN
INDIA
INTERNATIONAL
...
POST
/api/operators/create

Registra um novo operador espacial no sistema.

Request Body 

{
  "opName": "ISS Partnership",
  "role": "OPERATOR",
  "country": "INTERNATIONAL"
}
DELETE
/api/operators/delete/{operatorId}

Remove um operador cadastrado do sistema a partir do ID informado.

Documentação • Materiais

Os endpoints de materiais são responsáveis pelo gerenciamento dos materiais estruturais utilizados nos satélites cadastrados, incluindo informações relacionadas à reciclabilidade, reutilização e classificação estrutural.

GET
/api/materials

Retorna todos os materiais cadastrados no sistema.

GET
/api/materials/id/{materialId}

Retorna um material específico a partir do ID informado.

POST
/api/materials/create

Registra um novo material estrutural no sistema. Os materiais cadastrados posteriormente podem ser vinculados aos satélites registrados.

Request Body 

{
  "materialName": "Titanium",
  "recyclable": true,
  "reusableFor": "STRUCTURAL_COMPONENTS",
  "materialType": "METAL"
}

Exemplos de MaterialType 

METAL
POLYMER
COMPOSITE
CERAMIC
...

Exemplos de ReusableFor 

STRUCTURAL_COMPONENTS
SOLAR_PANELS
ELECTRONIC_CIRCUITS
AEROSPACE_ENGINEERING
THERMAL_PROTECTION
...
DELETE
/api/materials/delete/{materialId}

Remove um material previamente cadastrado do sistema.

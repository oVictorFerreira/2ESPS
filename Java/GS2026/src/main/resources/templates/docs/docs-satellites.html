Documentação • Satélites

Os endpoints de satélites são responsáveis pela integração com a TLE API, cadastro de satélites no sistema, associação de materiais estruturais e consulta consolidada de informações relacionadas à composição e reciclabilidade orbital.

GET
/api/satellites/operator/{operatorId}

Retorna todos os satélites associados a um operador específico.

GET
/api/satellites/status/{status}

Retorna todos os satélites cadastrados com determinado status operacional.

Exemplos de Status 

ACTIVE
INACTIVE
DEBRIS
UNKNOWN
POST
/api/satellites/create

Cria um satélite no banco de dados a partir do NORAD ID informado. O sistema consulta automaticamente a TLE API para obter o nome oficial do satélite.

Request Body 

{
  "noradId": 25544,
  "operatorId": 3,
  "status": "ACTIVE"
}
POST
/api/satellites/{noradId}/materials

Vincula materiais previamente cadastrados ao satélite informado, registrando peso estrutural, percentual de reciclabilidade e área estrutural relacionada.

Request Body 

{
  "materialId": 1,
  "totalWeightKg": 35000,
  "recyclablePercentage": 88,
  "structuralArea": "PressureModules"
}
GET
/api/satellites/id/{noradId}

Retorna informações completas do satélite, combinando dados obtidos da TLE API com os materiais registrados no banco de dados.

GET
/api/satellites/material/{type}

Retorna os satélites que possuem determinado tipo de material estrutural.

Exemplos de MaterialType 

METAL
POLYMER
COMPOSITE
CERAMIC
ELECTRONIC
SOLAR_COMPONENT
FUEL
GLASS

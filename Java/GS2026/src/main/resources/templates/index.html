Objetivo do Projeto

O Vlynk foi desenvolvido com o objetivo de centralizar informações relacionadas ao monitoramento de satélites espaciais e análise de materiais reutilizáveis presentes em estruturas orbitais. O sistema combina dados externos obtidos através da TLE API com informações internas registradas no banco de dados, permitindo consultas técnicas, análise de reciclabilidade e gerenciamento completo de operadores e composições estruturais.

Tecnologias Utilizadas

O projeto foi desenvolvido utilizando Java com Spring Boot, arquitetura RESTful, integração com APIs externas utilizando RestClient, persistência de dados com Spring Data JPA e H2 Database, além de documentação visual construída com Thymeleaf.

Consumo e Análise de API Externa

O projeto Vlynk realiza o consumo da API pública TLE API, utilizada para obtenção de informações orbitais de satélites, como NORAD ID e nome oficial dos objetos espaciais monitorados. O consumo da API ocorre de forma complementar ao sistema, permitindo validar e integrar dados externos com informações internas relacionadas a operadores, materiais estruturais e reciclabilidade dos satélites cadastrados.



Facilidade de Acesso

A API apresenta acesso simples e aberto, sem necessidade de autenticação complexa, permitindo integração rápida ao projeto.

Facilidade de Consumo

O retorno em JSON facilita o processamento utilizando RestClient no Spring Boot, simplificando a conversão dos dados para DTOs.

Integração com o Projeto

A API foi integrada diretamente ao fluxo de cadastro de satélites, permitindo obter automaticamente o nome oficial através do NORAD ID informado.

Velocidade de Resposta

Durante os testes realizados, a API apresentou respostas rápidas e estáveis para consultas individuais de satélites.

Performance média: ~0.8s

Documentação

A documentação da API apresenta exemplos claros de requisições e estrutura dos dados, facilitando significativamente a implementação e integração no sistema.
